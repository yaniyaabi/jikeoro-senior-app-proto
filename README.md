# 지켜路 쉬운 제보 앱 프로토타입

기존 지켜路 홈페이지와 별도로 만든 고령자용 모바일 PWA 프로토타입입니다. 휴대전화 브라우저에서 열고 홈 화면에 설치해 앱처럼 사용할 수 있습니다.

## 구현된 기능

- 큰 글자와 56px 이상의 주요 터치 버튼
- 기본 고대비 색상과 추가 고대비 모드
- 카메라 촬영 및 사진·영상 선택
- GPS 현재 위치 또는 장소 직접 입력
- 한국어 음성 받아쓰기와 음성 녹음
- 웹과 동일한 4단계 간편 제보 흐름(사진·영상 → 위험 설명·음성 → GPS 지도 위치 → 최종 확인)
- Supabase 로그인·회원가입과 사용자별 기록 분리
- 홈페이지와 동일한 상태 코드, 담당 기관 답변, 최근 수정 시각, 처리 이력을 사용하는 내 제보 현황
- 내 제보 첨부 사진·영상·음성 상세 확인·삭제
- 웹과 같은 마일리지·레벨·배지·월간 미션 규칙
- 10,000P부터 온누리상품권 등 지역상품권 교환을 안내하는 리워드 프로토타입
- 화면 제목 읽어주기
- 한국 시간 매일 오전 11시·오후 7시에 서로 다른 문구로 Web Push 알림
- 로그인한 미허용 기기에만 앱 시작 시 간단한 알림 허용 안내 (시간·횟수 선택 없음)
- 오프라인 재접속을 위한 PWA 서비스 워커

## 실행 방법

```bash
npm install
npm run dev
```

## 데이터 저장

계정·제보·처리 현황은 홈페이지와 동일한 Supabase 프로젝트에 저장됩니다. 사진·영상·음성은 비공개 Supabase Storage에 업로드되며, 제보 작성자와 운영진만 원본 파일을 조회할 수 있습니다. 작성 중인 임시 제보만 이 기기의 IndexedDB에 남아 앱을 닫았다가 다시 열어도 이어서 작성할 수 있습니다.

다른 Supabase 프로젝트를 사용할 때는 `.env.example`을 참고해 아래 값을 설정합니다.

```bash
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

`sb_secret_...` 또는 `service_role` 키는 앱 코드나 GitHub 저장소에 넣으면 안 됩니다.

## 보행 알림 서버

`supabase/migrations/202610260001_walking_reminders.sql`은 기기별 구독 저장소와 예약 작업을 추가합니다. `walking-reminders` Edge Function은 `supabase/config.toml`처럼 legacy JWT 검사를 끄고 함수 내부에서 사용자 JWT 또는 예약 작업 전용 비밀값을 검증합니다. VAPID 키는 서버에서 생성하여 클라이언트가 접근할 수 없는 설정 테이블에 저장하며 공개 키만 반환합니다. 다른 프로젝트로 옮길 때 SQL의 함수 호출 주소도 변경합니다.

예약 작업은 5분마다 실행하고 한국 시간 정각부터 10분 이내에 해당 시간의 구독을 발송합니다. `202610260002_fixed_daily_reminders.sql`부터 모든 구독은 오전 11시·오후 7시로 고정하며 같은 시간 중복 발송을 원자적으로 차단합니다. 기존 구독의 허용·비활성 상태는 유지합니다. 초기 연구실 테스트 규모를 위한 구성으로, 한 실행은 최대 500개 구독을 처리합니다. 전송 실패를 성공으로 표시하지 않으며 만료된 구독은 비활성화합니다. 로그아웃 시 현재 기기의 구독을 해제하고 다른 계정에 알림을 넘기지 않습니다.

아이폰은 iOS 16.4 이상에서 홈 화면에 설치한 뒤 알림을 허용해야 합니다. 브라우저·OS의 차단이나 집중 모드 때문에 정확한 도착 시간은 보장할 수 없습니다. 알림을 켠 기기에는 허용 팝업을 표시하지 않습니다. 로그인 전에는 알림 권한 요청이나 구독을 만들지 않습니다. 로그인 세션이 없는 상태로 앱을 열면 기존 기기 구독을 해제합니다. 로그인한 미허용 기기는 새 페이지 로드 및 1분 이상 백그라운드에 있다 돌아올 때 다시 안내합니다. ‘나중에’를 누르면 같은 실행 중에는 재촉하지 않습니다. OS에서 차단한 경우 권한창 대신 설정 안내를 표시합니다. 알림 끄기는 휴대폰 설정에서 가능합니다.

검증: `npm run build`, `npm test`.
