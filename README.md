# 지켜路 쉬운 제보 앱 프로토타입

기존 지켜路 홈페이지와 별도로 만든 고령자용 모바일 PWA 프로토타입입니다. 휴대전화 브라우저에서 열고 홈 화면에 설치해 앱처럼 사용할 수 있습니다.

## 구현된 기능

- 큰 글자와 56px 이상의 주요 터치 버튼
- 기본 고대비 색상과 추가 고대비 모드
- 카메라 촬영 및 사진·영상 선택
- GPS 현재 위치 또는 장소 직접 입력
- 한국어 음성 받아쓰기와 음성 녹음
- 3단계 간편 제보 흐름
- 내 제보 처리상태 확인
- 주간 퀘스트·마일리지·배지
- 화면 제목 읽어주기
- 오프라인 재접속을 위한 PWA 서비스 워커

## 실행 방법

```bash
npm install
npm run dev
```

## 데이터 저장

현재는 기능 시연용이므로 제보와 미디어가 사용자의 브라우저 IndexedDB에만 저장됩니다. 실제 조사 전에는 AWS S3, API, 인증 및 공간 데이터베이스를 연결해야 합니다.

## 배포

```bash
npm run build
```

생성된 `dist` 폴더를 별도의 GitHub Pages 저장소에 배포할 수 있습니다.
