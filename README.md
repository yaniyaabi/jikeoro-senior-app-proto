# 지켜路 쉬운 제보 앱 프로토타입

기존 지켜路 홈페이지와 별도로 만든 고령자용 모바일 PWA 프로토타입입니다. 휴대전화 브라우저에서 열고 홈 화면에 설치해 앱처럼 사용할 수 있습니다.

## 구현된 기능

- 큰 글자와 56px 이상의 주요 터치 버튼
- 기본 고대비 색상과 추가 고대비 모드
- 카메라 촬영 및 사진·영상 선택
- GPS 현재 위치 또는 장소 직접 입력
- 한국어 음성 받아쓰기와 음성 녹음
- 웹과 동일한 4단계 간편 제보 흐름(사진·영상 → 위험 설명·음성 → GPS 지도 위치 → 최종 확인)
- 로그인·회원가입 프로토타입과 사용자별 기록 분리
- 내 제보 처리상태 및 첨부 사진·영상·음성 상세 확인·삭제
- 웹과 같은 마일리지·레벨·배지·월간 미션 규칙
- 10,000P부터 온누리상품권 등 지역상품권 교환을 안내하는 리워드 프로토타입
- 화면 제목 읽어주기
- 오프라인 재접속을 위한 PWA 서비스 워커

## 실행 방법

```bash
npm install
npm run dev
```

## 데이터 저장

현재는 기능 시연용이므로 계정은 브라우저 저장소에, 제보와 미디어는 사용자의 브라우저 IndexedDB에 저장됩니다. 따라서 새 계정은 0P·배지 0개·기록 0건으로 시작하며, 이 단계에서는 홈페이지와 앱의 데이터가 실제로 공유되지는 않습니다.

추후 AWS 연결 시에는 현재 화면과 계산 규칙은 유지하고 아래 저장 부분만 교체할 수 있도록 구성했습니다.

- 로그인·회원가입 및 세션: Amazon Cognito
- 제보 및 참여 데이터: API Gateway/Lambda와 데이터베이스
- 사진·영상·음성: Amazon S3
- 홈페이지·앱: 같은 사용자 ID로 기록, 마일리지, 배지를 함께 조회

## 배포

```bash
npm run build
```

생성된 `dist` 폴더를 별도의 GitHub Pages 저장소에 배포할 수 있습니다.
