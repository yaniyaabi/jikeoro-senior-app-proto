# 지켜路 쉬운 제보 앱 프로토타입

기존 지켜路 홈페이지와 별도로 만든 고령자용 모바일 PWA 프로토타입입니다. 휴대전화 브라우저에서 열고 홈 화면에 설치해 앱처럼 사용할 수 있습니다.

## 구현된 기능

- 큰 글자와 56px 이상의 주요 터치 버튼
- 기본 고대비 색상과 추가 고대비 모드
- 카메라 촬영 및 사진·영상 선택
- GPS 현재 위치 또는 장소 직접 입력
- 한국어 음성 받아쓰기와 음성 녹음
- 웹과 동일한 4단계 간편 제보 흐름(사진·영상 → 위험 설명·음성 → GPS 지도 위치 → 최종 확인)
- Supabase 로그인·회원가입과 사용자별 기록 분리
- 홈페이지와 동일한 상태 코드, 담당 기관 답변, 최근 수정 시각, 처리 이력을 사용하는 내 제보 현황
- 내 제보 첨부 사진·영상·음성 상세 확인·삭제
- 웹과 같은 마일리지·레벨·배지·월간 미션 규칙
- 10,000P부터 온누리상품권 등 지역상품권 교환을 안내하는 리워드 프로토타입
- 화면 제목 읽어주기
- 오프라인 재접속을 위한 PWA 서비스 워커

## 실행 방법

```bash
npm install
npm run dev
```

## 데이터 저장

계정·제보·처리 현황은 홈페이지와 동일한 Supabase 프로젝트에 저장됩니다. 사진·영상·음성은 비공개 Supabase Storage에 업로드되며, 제보 작성자와 운영진만 원본 파일을 조회할 수 있습니다. 작성 중인 임시 제보만 이 기기의 IndexedDB에 남아 앱을 닫았다가 다시 열어도 이어서 작성할 수 있습니다.

다른 Supabase 프로젝트를 사용할 때는 `.env.example`을 참고해 아래 값을 설정합니다.

```bash
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

`sb_secret_...` 또는 `service_role` 키는 앱 코드나 GitHub 저장소에 넣으면 안 됩니다.

## 배포

```bash
npm run build
```

생성된 `dist` 폴더를 별도의 GitHub Pages 저장소에 배포할 수 있습니다.
